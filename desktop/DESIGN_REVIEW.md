# 2026-10-12 界面参考图实现记录

本次以用户提供的四张参考图为准：主页输入和本次选项、连续阅读、封面笔记库、单列设置。原生 GPUI 实现，未引入网页替代界面。

## 组合与标尺

- 主页保留 720px 工作区；单个链接输入栏、可展开的本次选项和最近笔记列表。
- 笔记库最大内容宽度 1120px，标题与搜索共用一行，窄窗口换行；封面与标题不再套外层卡片。
- 阅读列 48rem，目录按需打开；摘要统一底色，图片使用正文列宽。紧凑窗口标题随正文滚动。
- 设置最大内容宽度 800px，默认值、保存、账号与外观依次排列。标签与控件使用共享可换行行结构；说明与控件共用起点。
- Ink 更新为中性深灰与淡蓝色操作；其他配色和已保存的明暗偏好保持原有身份。

## 独立复核与处理

| 页面 | 发现 | 处理 |
| --- | --- | --- |
| 设置 | 分类导航移除后仍聚焦未挂载句柄 | 将当前焦点挂载到实际设置面板 |
| 主页/设置 | 截图辅助校对时发送说明只提文字 | 根据校对与截图开关显示真实发送内容 |
| 笔记库 | 简化元信息后失去文件夹归属 | 未分组视图保留简短文件夹信息 |
| 主页实机截图 | 最近笔记图片仍呈方角 | 图片本身应用共享圆角，避免仅父容器有圆角 |
| 阅读 | 紧凑工具栏新增搜索与目录后可能溢出 | 第二行放置搜索和目录，第一行允许换行 |
| 阅读 | 长标题可能占满固定页头 | 紧凑模式标题进入正文/截图页滚动区域 |
| 阅读 | 加载时全局导航隐藏，缺少返回 | 加载状态提供上下文返回操作 |
| 设置 | 文字来源说明固定描述自动模式 | 按自动/仅字幕/语音识别分别显示后果 |
| 设置 | 导出选项右对齐，偏离控件起点 | 格式容器使用整列宽度 |

主页、笔记库、设置、阅读的加载、空内容、错误、完成、保存恢复分支已进行交叉源码复核。复核者不单独验收自己实现的页面。

## 验证证据与边界

桌面端离线编译通过；桌面测试 232 项通过、3 项按现有配置忽略。为避免重建与本次 UI 无关的 Swift ASR，UI 检查使用 `COURSE2MD_NO_APPLE=1`。该结果不代表 Apple 语音识别集成验收。

已启动独立配置的原生测试版，在 1280×900 窗口捕获深色主页。合成 18 秒视频通过字幕转换生成了可读笔记；这是引擎验证，不是界面内完整生成流程验证。
