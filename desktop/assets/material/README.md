# Embedded Material Icons

Original 24px **Material Icons Rounded** SVGs from Google's
[material-design-icons](https://github.com/google/material-design-icons), Apache-2.0 ([LICENSE](LICENSE)).
`sources.json` records the upstream revision and original category/name of each icon.
The artwork is unmodified; filenames match GPUI Component's asset paths.

`desktop/src/icons.rs` embeds them. Lucide outline icons in `../outline/` take
precedence for shared navigation, actions and settings.
