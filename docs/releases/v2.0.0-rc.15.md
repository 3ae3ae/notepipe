# v2.0.0-rc.15：读取动画更流畅、视频列表滚动修复

这是 **2.0 的第十五个候选发布版（RC15）**。本版修复两个界面问题。稳定版 Latest 保持不变。

## 相比 RC14

- **动画按屏幕刷新率运行**：读取视频信息时的进度条、加载图标和页面切换动画此前最多只有约 30 帧，在 ProMotion 屏幕上更明显；现在与屏幕刷新同步。
- **视频列表滚动不再带动整页**：输入合集或播放列表链接后，在候选视频列表中滚动只滚动列表本身，页面保持不动；列表较短无需滚动时，滚轮仍滚动页面。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.15/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.15/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.15/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp；安装 aria2 后模型多线程下载。Homebrew 会安装这些依赖，Windows 桌面包已内置 aria2；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 的 RC 通道：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## English

**2.0 RC15** fixes two interface issues. Loading and page motion — including the progress bar shown while reading a video's information — now runs at the display's refresh rate instead of roughly 30fps. Scrolling inside the candidate list of a playlist or collection no longer scrolls the whole page as well.

Use the platform assets above or the independent Homebrew RC channels. These fixes were tested automatically but not checked by hand; please report any issues.
