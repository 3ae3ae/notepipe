# v2.0.0-rc.11：修复 yt-dlp 误报

这是 **2.0 的第十一个候选发布版（RC11）**。本版修复桌面端在已安装 Homebrew/PATH 版 yt-dlp 时仍误报“未安装”，并修正 macOS 应用内随包 yt-dlp 的签名，使其可以加载 Python 运行时。RC10 的四语言界面、性能与保存可靠性改进全部保留，稳定版 Latest 保持不变。

## 相比 RC10

- **修复 yt-dlp 误报**：应用会依次验证随包、PATH、Homebrew 和常见安装目录中的 yt-dlp；某个候选文件存在但无法运行（例如 macOS 签名阻止其加载 Python）时会继续尝试下一个，而不是直接显示“未安装”。
- **修复 macOS 随包 yt-dlp**：为嵌套的 yt-dlp 增加禁用库验证的签名 entitlement，随包版本可以正常启动；仍优先使用能实际运行的那一份。
- **四语言界面**：应用界面、桌面提示和用户可见的引擎消息支持英文、简体中文、繁体中文和日文，可在「设置 → 外观」即时切换；机器可读的 `--json` 与 `run-task` 协议保持稳定。
- **更流畅的阅读与笔记库**：阅读页查找、截图画廊摘要、任务队列、最近笔记、封面和笔记库筛选使用缓存或索引，不再在每次重绘时重复扫描。
- **更可靠的保存**：设置、服务、账号与任务记录写入移到后台；界面先显示「正在保存…」，落盘成功后才显示「已保存」。保存失败会保留恢复文件或 intent，并提供重试。
- **任务启动与恢复**：字幕读取、校验和文件哈希计算移出界面线程；任务事件直接唤醒界面，阅读位置、提示过期和退出超时使用明确的截止时间。
- **大字号与窄窗口**：修复 150%/200% 字号下设置侧栏断词、宽窗口标签错位、760px 窄窗转录来源标签截断等问题。
- **服务与账号**：服务测试结果、账号状态和失败原因使用类型化数据；二维码登录、退出登录和凭据操作移出 UI 线程。
- **文案与细节**：统一「中文 / English」引擎帮助、设置标签大小写、任务阻塞原因和错误提示。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.11/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.11/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp。Homebrew 会安装这些依赖；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 的 RC 通道：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

## English

**2.0 RC11** fixes the desktop app reporting yt-dlp as missing when Homebrew/PATH has a working copy, and fixes the macOS bundled yt-dlp signature so it can load its Python runtime. It adds English, Simplified Chinese, Traditional Chinese and Japanese interfaces and focuses on desktop reliability: cached reader/library views, background settings and task-record writes, confirmed save feedback with recovery on failure, and fixes for 150%/200% text, wide layouts and the 760px narrow workbench. All themes, settings and existing notes are preserved. Stable Latest remains unchanged.

Use the platform assets above or the independent Homebrew RC channels. Windows and Linux builds were tested automatically but not checked by hand; please report any issues.
