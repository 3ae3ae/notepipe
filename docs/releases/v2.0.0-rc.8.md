# v2.0.0-rc.8：随包自带 yt-dlp，统一定位与 doctor 诊断

这是 **2.0 的第八个候选发布版（RC8）**。本版聚焦 yt-dlp 的可靠定位与分发：CLI 和桌面端使用同一搜索清单，安装包与 install.sh 随包自带 yt-dlp 独立二进制，桌面会话拿不到登录 shell PATH 时不再误报「缺少 yt-dlp」，`course2md doctor` 也会报告实际使用的 yt-dlp 路径。界面与 RC7 一致。GitHub Latest、默认 Homebrew 包和 AUR 稳定包继续提供稳定版；试用 RC8 请使用本页附件或独立 RC 通道。

## 相比 RC7

- **统一 yt-dlp 搜索清单**：CLI 与桌面端共用同一套定位逻辑（`COURSE2MD_YTDLP` 环境变量 → 可执行文件旁随包版本 → PATH → Homebrew/pipx/mise/asdf/conda/Nix/Scoop/WinGet/Python user-base 等常见目录），两边行为不再分叉。
- **随包自带 yt-dlp**：install.sh 与桌面安装包（DMG/ZIP/tar.gz）现在携带独立的 yt-dlp 二进制，放在与 course2md 可执行文件同目录；PATH 中已有 yt-dlp 时继续沿用系统版本，Homebrew/AUR 的 yt-dlp 依赖保持不变。
- **桌面端不再误报缺失**：GUI 进程拿不到登录 shell 的 PATH 时，会优先使用随包 yt-dlp 或按统一清单搜索，不再弹出「缺少 yt-dlp」。
- **doctor 显示实际路径**：`course2md doctor` 现在会输出当前实际使用的 yt-dlp 路径，方便排查。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.8/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.8/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.8/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp。Homebrew 会安装这些依赖；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或 alpha/旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui`、`course2md-gui@alpha` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。手动安装过的应用可先移出「应用程序」留作备份。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 也有 RC 通道，默认不替换终端中的稳定版命令：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC7 升级可直接覆盖安装，保留配置、课程输出及模型缓存。
- 本版改动经本地回归验证：引擎与集成测试通过；yt-dlp 定位、随包分发与 `doctor` 输出在 macOS CLI 路径下核对。
- 已知验证边界：桌面端实机安装包未逐平台拆包确认 yt-dlp 二进制存在；Windows/Linux 原生桌面启动未实机检查；各平台 PATH 与随包版本的优先级组合未穷尽测试。

启动后在「设置 → 应用」确认版本 `2.0.0-rc.8`；CLI 使用 `--version` 确认。反馈问题时请附系统、版本、复现步骤和已脱敏的诊断信息。

## English

**2.0 RC8** focuses on reliable yt-dlp discovery and distribution: the CLI and desktop app now share a single lookup list (`COURSE2MD_YTDLP` → bundled copy next to the executable → PATH → common package-manager directories), install.sh and desktop bundles ship a standalone yt-dlp binary alongside the executable, the GUI no longer reports "yt-dlp missing" when it cannot see the login-shell PATH, and `course2md doctor` prints the resolved yt-dlp path. UI is unchanged from RC7.

Use the platform assets above or the independent Homebrew `course2md-gui@rc` and `course2md-rc` channels. Stable packages remain unchanged. Verified locally for CLI lookup and `doctor` output on macOS; not yet exhaustively verified across packaged desktop bundles on all platforms.
