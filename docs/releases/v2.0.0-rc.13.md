# v2.0.0-rc.13：修复阅读页滚动闪退

这是 **2.0 的第十三个候选发布版（RC13）**。本版修复 RC12 中打开笔记后一滚动就闪退的问题，RC12 的其他改进全部保留。稳定版 Latest 保持不变。

## 相比 RC12

- **修复滚动闪退**：RC12 中，打开任意笔记后第一次滚动，应用就会退出。现已修复；滚回顶部时，标题、来源信息和播放按钮也会重新出现。
- **构建检查**：修复 Linux 与 Windows 上的代码检查失败。

## RC12 的主要改进

- **数学公式**：AI 校对和摘要把公式写成 LaTeX，阅读页和 HTML 导出直接排版显示，颜色跟随深浅色模式；被字幕分段拆开的公式自动合并。
- **AI 请求更可靠**：响应 90 秒没有数据即判定中断；Codex 和本机 Ollama 等不按次计费的服务自动重发，按次计费的 API 仍先询问。
- **阅读页、菜单与设置按新设计改版**，任务进度保留已完成阶段，并显示用时与已返回的 tokens。完整说明见 [RC12 发布说明](https://github.com/mizorewww/course2md/releases/tag/v2.0.0-rc.12)。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 的 RC 通道：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC12 或更早的 RC 升级可直接覆盖安装，保留配置、课程输出及模型缓存。
- 已知限制：Windows 与 Linux 版本只经过自动构建和测试，没有人工检查界面。如遇问题请[反馈](https://github.com/mizorewww/course2md/issues)。

启动后在“设置 → 应用”确认版本 `2.0.0-rc.13`；CLI 使用 `--version` 确认。

## English

**2.0 RC13** fixes the RC12 crash on the first scroll in any note; the note header also returns when you scroll back to the top. All RC12 improvements are kept: typeset LaTeX formulas in the reader and HTML export, automatic resending for services without per-request billing, and the redesigned reader, menus and settings. Stable Latest remains unchanged.

Use the platform assets above or the independent Homebrew RC channels. Windows and Linux builds were tested automatically but not checked by hand; please report any issues.
