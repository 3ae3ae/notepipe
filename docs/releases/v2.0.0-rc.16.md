# v2.0.0-rc.16：笔记库文件夹树、任务页重做、分集视频的处理选项

这是 **2.0 的第十六个候选发布版（RC16）**。本版重做笔记库与任务页，并修复分集视频预览后无法打开处理选项的问题。稳定版 Latest 保持不变。

## 相比 RC15

### 笔记库

- **文件夹树**：笔记旁边改为一棵树，依次是全部笔记、各个笔记库及其中的文件夹。选中某处会先以图块显示其中的文件夹，再显示笔记，上方的路径可逐级返回。窗口较窄时，树收进路径开头的菜单。
- **文件夹可以嵌套**：文件夹可以放进其他文件夹。同一层级内名称不能重复，文件夹不能移进自身；删除文件夹会一并删除其中的子文件夹，笔记保留在笔记库中，变为未归档。
- **整理方式与文件管理器一致**：笔记和文件夹可以拖到文件夹上，也可以用「移动到」。文件夹、图块和笔记库顶层都有右键菜单，可打开、新建子文件夹、重命名、移动和删除。
- **键盘操作**：方向键在树中移动、展开和折叠，Return 或空格打开，⌘⌫ 确认后删除文件夹。在笔记库或文件夹内搜索，会包含其下所有子文件夹中的笔记。
- **删除仅存于 iCloud 的笔记**：笔记库在 iCloud 云盘中、文件已被 macOS 移出本机时，笔记也能移到废纸篓；删除时不再经过访达，也就不会弹出访达的错误提示或播放访达的音效。
- **阅读**：笔记标题区随正文滚动，不再在滚动时收起、导致正文跳动；在标题区内保存的阅读位置会恢复到顶部。列表中各项之间的间距不再丢失。

### 任务

- **任务页重做**：页首汇总全部任务，可一键暂停或继续全部任务。正在运行的任务显示为一张卡片，包括当前步骤、已完成的每一步及其用时，以及提交时的设置和控制按钮；排队中的任务按运行顺序排列，可以拖动调整顺序。需要处理的任务、已完成的任务和较早的尝试显示为可就地展开的行。
- **菜单更完整**：每一行都有 ⋯ 菜单，右键菜单包含所有适用的命令，例如阅读、打开位置、原视频及其链接、详情与日志、调整队列顺序、暂停、继续、修复、重试、调整和取消。任务菜单还可以重新关联存储位置。
- **暂停的任务保留原位**：暂停的任务留在队列中原来的位置，不再移到「需要处理」，继续后也从原位置运行。窗口较窄或字号较大时，行内的按钮换行显示，不再遮住标题。

### 新建笔记

- **分集视频的处理选项**：预览 Bilibili 分集（多 P）视频后，点击链接框中的「处理选项」按钮，面板可以正常展开，此前点击没有反应。面板中的设置也会应用到批量加入队列的分集。
- **按任务选择双语翻译**：「处理选项」的 AI 处理部分新增「双语翻译」，可为本次转换单独选择目标语言或不翻译，默认沿用「设置 → 生成笔记」中的选择。

### 构建

- 从源码构建时不再下载 SwiftPM 预编译的 swift-syntax。网络较慢时，此前首次构建可能一直卡住。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.16/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.16/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.16/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp；安装 aria2 后模型多线程下载。Homebrew 会安装这些依赖，Windows 桌面包已内置 aria2；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 的 RC 通道：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC15 或更早的 RC 升级可直接覆盖安装，保留配置、课程输出及模型缓存；已下载的模型不会重新下载。已有的文件夹全部成为顶层文件夹；旧版本仍可读取新的笔记库记录，不会打乱文件夹结构。
- 在「设置」中选过双语翻译的用户，升级后未提交的输入会沿用该设置。
- 已知限制：分集视频的处理选项和按任务翻译已在 macOS 上人工检查；Windows 与 Linux 版本只经过自动构建和测试。如遇问题请[反馈](https://github.com/mizorewww/course2md/issues)。

启动后在“设置 → 应用”确认版本 `2.0.0-rc.16`；CLI 使用 `--version` 确认。

## English

**2.0 RC16** reworks the note library and the task page. The library is now a folder tree beside the notes, with nested folders, drag-and-drop or "Move to", file-manager context menus and keyboard navigation; searching inside a folder covers its subfolders. Notes stored only in iCloud can be moved to the trash. The task page summarises all work, shows the running task's steps, and lets you drag queued tasks into a new order; paused tasks keep their place in the queue.

After previewing a multi-part Bilibili video, the processing options panel now opens, and its settings apply to the parts you queue. Bilingual translation can also be chosen per conversion from that panel; it defaults to the target set in Settings.

Use the platform assets above or the independent Homebrew RC channels. The processing options and per-task translation were checked by hand on macOS; the Windows and Linux builds were tested automatically only. Please report any issues.
