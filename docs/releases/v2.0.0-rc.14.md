# v2.0.0-rc.14：大陆网络下载模型、双语翻译、删除笔记

这是 **2.0 的第十四个候选发布版（RC14）**。本版解决中国大陆用户下载识别模型卡住的问题，并新增双语翻译和删除笔记。稳定版 Latest 保持不变。

## 相比 RC13

- **大陆网络下载模型不再卡住**：自动识别网络所在地区。中国大陆依次使用 ModelScope、hf-mirror.com，最后才是 Hugging Face；其他地区优先 Hugging Face。某个地址失败时自动换下一个；设置 `HF_ENDPOINT` 时仍以它为准。
- **下载更稳**：一分钟没有收到数据即换线或重连，中断后从断点续传，不再从头下载 2.4GB；下载完成后按官方 SHA-256 校验。装有 aria2 时多线程下载。
- **下载进度更清楚**：每个模型文件显示下载来源，以及“正在连接”“连接中断，正在重新连接”“正在校验文件完整性”等状态。
- **双语翻译**：在“设置 → AI 处理 → 双语翻译”选择目标语言（简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español）。AI 校对后每段下方附上译文，阅读页、Markdown、HTML 与 JSON 导出均包含；视频已是目标语言时不翻译。CLI 使用 `--translate <LANG>`。
- **删除笔记**：笔记的 ⋯ 菜单与右键菜单新增“删除笔记…”，确认后移到废纸篓（Windows 为回收站），可以恢复。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.14/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.14/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.14/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp；安装 aria2 后模型多线程下载。Homebrew 会安装这些依赖，Windows 桌面包已内置 aria2；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 的 RC 通道：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC13 或更早的 RC 升级可直接覆盖安装，保留配置、课程输出及模型缓存；已下载的模型不会重新下载。
- 双语翻译与 AI 校对、摘要使用同一 AI 服务，会额外消耗 tokens。
- 已知限制：本版的新设置、删除确认与下载进度界面只经过自动测试，没有人工点击检查；Windows 与 Linux 版本只经过自动构建和测试。如遇问题请[反馈](https://github.com/mizorewww/course2md/issues)。

启动后在“设置 → 应用”确认版本 `2.0.0-rc.14`；CLI 使用 `--version` 确认。

## English

**2.0 RC14** fixes speech model downloads that stalled in mainland China. The app now detects the network's region and downloads from ModelScope or hf-mirror.com there, falling back to Hugging Face; `HF_ENDPOINT` still overrides this. Downloads resume after interruptions, switch hosts after a minute without data, are verified against the published SHA-256, and use aria2 for multiple connections when it is installed (bundled on Windows). Each model file shows its host and whether it is connecting, reconnecting or verifying.

New: **bilingual notes** — choose a target language under Settings → AI processing; each paragraph is followed by its translation in the reader and exports, and videos already in that language are not translated (`--translate <LANG>` in the CLI). **Delete notes** from the ⋯ or right-click menu; they move to the Trash and can be restored.

Use the platform assets above or the independent Homebrew RC channels. The new screens were tested automatically but not checked by hand; please report any issues.
