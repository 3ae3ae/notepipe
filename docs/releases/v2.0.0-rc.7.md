# v2.0.0-rc.7：桌面端 Material 3 重新设计，删除冗余说明并统一对齐

这是 **2.0 的第七个候选发布版（RC7）**。本版是一次桌面端界面整理：按 Material 3 规范重新设计顶栏、工作台、设置、笔记库与阅读页，删除大量例行说明文字与重复状态，并把标签、副行、行尾按钮和阅读页正文统一到共享的对齐线上。引擎行为与 RC6 一致。GitHub Latest、默认 Homebrew 包和 AUR 稳定包继续提供稳定版；试用 RC7 请使用本页附件或独立 RC 通道。

## 相比 RC6

- **Material 3 重新设计**：顶栏改为左侧品牌、右侧笔记库/设置；工作台收为居中单列与一体化胶囊链接输入；颜色、控件、图标与动效收敛到共享设计原语。
- **删除冗余**：清理各页例行说明文字；运行检查全部可用时合并为一行「一切正常」并以标签列出能力；只有一个保存位置时不再显示「默认保存位置」徽章与说明；Bilibili 未登录时不再显示「重新检查」；「AI 服务连接」并入「AI 服务」，Codex 与 Ollama 排在服务列表前。
- **统一对齐**：设置项说明与副行从标签文字起排；行尾文字按钮贴齐卡片内容边缘；展开项箭头落在图标槽；阅读页返回键并入工具栏，标题、信息与正文共用同一边缘。
- **内部改进**：多处重复实现收敛；阅读页预览与查找改为共享引用，消除每次击键的全文拷贝；修复 Windows 下只查 `.exe` 导致 `.bat`/`.cmd` 形式工具漏检；引导页模型准备按钮文案与设置页统一。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.7/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.7/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.7/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp。Homebrew 会安装这些依赖；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或 alpha/旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui`、`course2md-gui@alpha` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。手动安装过的应用可先移出「应用程序」留作备份。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 也有 RC 通道，默认不替换终端中的稳定版命令：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC6 升级可直接覆盖安装，保留配置、课程输出及模型缓存。
- 本版改动经 macOS 本机回归验证：引擎 155 项、集成 23 项、桌面 232 项测试全部通过；工作台、设置（各分区）、笔记库与阅读页在运行中的原生应用中以 1280 与 900 宽窗口逐页核对。
- 已知验证边界：任务运行中状态、引导第 3–4 步与 200% 缩放未逐项实机检查；阅读页目录与摘要卡片尚未按设计稿实现；「诊断详情」数值列尚未对齐；Windows/Linux 原生视觉仍需进一步试用。

启动后在「设置 → 应用」确认版本 `2.0.0-rc.7`；CLI 使用 `--version` 确认。反馈问题时请附系统、版本、复现步骤和已脱敏的诊断信息。

## English

**2.0 RC7** is a desktop UI overhaul following Material 3: a redesigned top bar, a centered single-column workbench with an integrated link input, and settings, library and reader pages rebuilt on shared design primitives. Routine explanatory text and duplicated status were removed (an all-clear environment check collapses to a single "all good" row; single-location storage hides the default badge; the separate "AI service connections" group merged into "AI services"), and labels, supporting lines, trailing buttons and the reader body now share common alignment edges. Engine behaviour is unchanged from RC6, plus a Windows fix for detecting `.bat`/`.cmd` tools.

Use the platform assets above or the independent Homebrew `course2md-gui@rc` and `course2md-rc` channels. Stable packages remain unchanged. Verified on macOS (155 engine + 23 integration + 232 desktop tests; page-by-page inspection of the running native app at 1280 and 900 wide). Not yet covered: running-task states, onboarding steps 3–4, 200% scale, the reader table of contents and summary card (not yet implemented), and Windows/Linux visuals.
