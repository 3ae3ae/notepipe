# v2.0.0-rc.12：数学公式、可靠的 AI 请求与新界面

这是 **2.0 的第十二个候选发布版（RC12）**。本版让笔记里的数学公式可以直接阅读，修复长视频中 AI 请求中断后整段校对和摘要丢失的问题，并按新设计改版阅读页、设置与菜单。稳定版 Latest 保持不变。

## 相比 RC11

- **数学公式**：AI 校对和摘要会把公式写成 LaTeX（行内 `$…$`，独立成行 `$$…$$`），口述的公式也会改写。阅读页和 HTML 导出直接排版显示，颜色跟随深浅色模式；被字幕分段拆开的公式会自动合并。
- **AI 请求不再整段丢失**：此前服务返回后停止输出时，请求要等满 5 分钟才标为“待确认”，并阻止后续所有请求。现在 90 秒没有数据即判定中断；Codex（ChatGPT 订阅额度）和本机 Ollama 等不按次计费的服务会自动重发，最多 3 次，上次留下的待确认请求也会自行补发。按次计费的 API 仍在重发前询问。
- **阅读页改版**：摘要卡片（要点两栏）、截图与正文左右交替的章节、截图上的跳转播放；标题栏显示路径和阅读工具，滚动后标题区收起，把空间留给正文。截图完整显示不再裁切。
- **任务进度**：已完成的阶段保留在原位，当前阶段接在下方；AI 校对等没有进度比例的步骤显示用时和已返回的 tokens（例如 `用时 3m09s · ↓ 22.0k tokens`）。
- **菜单与设置**：统一的下拉菜单和选择框；笔记、任务、服务等大部分列表支持右键菜单；所有 AI 服务在一个列表中按类型添加；输入框改为带浮动标签的描边样式；主页可隐藏“最近的笔记”，左上角改为主页图标。
- **修复与细节**：链接框粘贴本地文件路径会按本地视频导入；选择应用包或文件夹时提示“不是视频文件”；只有服务确实拒绝配置时才显示“修复 AI 服务”；应用被强制退出后后台任务会在安全节点停止；Codex 模型列表获取失败时显示具体原因。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.12/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.12/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.12/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp。Homebrew 会安装这些依赖；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 的 RC 通道：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC11 升级可直接覆盖安装，保留配置、课程输出及模型缓存。已有笔记中的公式仍是原文；重新生成或补做 AI 校对后才会写成 LaTeX。
- 本版在 macOS 上用一段 118 分钟的高等数学课程（Codex `gpt-6-astra`）完整验证了导入、处理、阅读与导出。
- 已知限制：Windows 与 Linux 版本只经过自动构建和测试，没有人工检查界面。如遇问题请[反馈](https://github.com/mizorewww/course2md/issues)。

启动后在“设置 → 应用”确认版本 `2.0.0-rc.12`；CLI 使用 `--version` 确认。

## English

**2.0 RC12** makes math in notes readable: proofreading and summaries write formulas as LaTeX, and the reader and HTML export typeset them in the current light or dark theme; formulas split across subtitle segments are joined. AI requests no longer lose whole sections of a long video: a stalled response is detected after 90 seconds, and services without per-request billing (Codex on a ChatGPT plan, local Ollama) resend unconfirmed requests automatically; billed APIs still ask first. The reader, settings and menus follow the new design: a summary card, alternating screenshot and text sections, reader tools in the title bar, one menu and select style, right-click menus, and a single AI service list. Task stages stack in place and unmeasured steps show elapsed time and received tokens. Stable Latest remains unchanged.

Use the platform assets above or the independent Homebrew RC channels. Windows and Linux builds were tested automatically but not checked by hand; please report any issues.
