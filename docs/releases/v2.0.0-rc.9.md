# v2.0.0-rc.9：视频预览确认与桌面排版改进

这是 **2.0 的第九个候选发布版（RC9）**。本版改进视频预览与生成确认，按三档窗口设计参考调整首页和设置页，并统一选项的图标与文字居中。保留全部主题、完整设置和现有笔记。稳定版 Latest 保持不变。

## 相比 RC8

- **先预览再转换**：输入视频链接、按 Enter、选择或拖入本地视频先读取信息，只有明确点击“开始转换”才创建任务。链接输入保持可见，预览卡紧接输入栏下方。
- **首页响应式排版**：统一大标题、输入、最近笔记、处理选项的间距；宽窗口使用双列，窄窗口将处理选项放在最近笔记之前。完善读取中、失败、空笔记库、处理进度和拖入文件状态。
- **完整设置重新排版**：外观、生成笔记、服务与账号、存储、应用五类设置统一侧栏、卡片、表单和辅助文字。保留主题、模型、服务及高级参数。
- **界面细节**：选项的图标与文字对齐居中，切换选项时内容不再跳动；开关、按钮和图标的尺寸统一，并改用线框图标。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.9/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.9/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.9/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp。Homebrew 会安装这些依赖；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或 alpha/旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui`、`course2md-gui@alpha` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。手动安装过的应用可先移出「应用程序」留作备份。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 也有 RC 通道，默认不替换终端中的稳定版命令：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。
