## 第三轮：运行验证（2026-09-15 凌晨）

在运行应用上做的端到端验证（非源码推断）：

- **模型下载全流程**：2.4GB 实下载，进度条持续推进（52MB→855MB）、速度与剩余时间实时更新、「暂停准备」生效、恢复时显示「尚未下载完整，继续准备会复用已有文件」。统一为 250ms 节拍与共享阶段判定后，卡片文案与进度一致。
- **任务调度全链路**：排队任务在无凭据需求时即时启动（run-task 子进程可见）→ 运行 → 完成。完成卡片为「阅读笔记」（填充强调）+「修复 AI 服务并补做」（描边恢复入口）+「查看任务详情」（安静动作）；AI 服务 401 被正确归类为凭据/权限问题，文案为「校对、摘要尚未完成。AI 服务未接受此任务的凭据或权限，请修复服务后补做。」；笔记库条目显示「部分内容待补全」徽记，任务终态为 partial。
- **引擎端到端（CLI，合成 62 秒中文语音视频）**：CoreML ASR 完整转写、笔记/HTML/ZIP 产物齐全；AI 服务不可达时保留原文并给出一次性明确警告。
- **冻结根因实证**：sample 显示主线程阻塞在 SecItemCopyMatching（后台 executor 任务经 GCD queue override 跑在主线程）；全部阻塞 IO 迁至 `spawn_blocking_io`（专用 OS 线程）后，主线程回到 run loop 空闲等待，Keychain 弹窗排队期间界面保持可用。
- **浅色 Paper 主题 / 降低动态效果开关 / 高级选项对象行 / 阅读器修复 / 笔记库文件夹图标与间距**：截图逐项确认（r6 系列）。

环境备注：验证期间另一应用的 Keychain 密码弹窗（SecurityAgent）会抑制合成输入，属系统行为；course2md 自身在该场景下已不再冻结。
